# RetinaCare-AI Frontend

React + TypeScript + Tailwind CSS web interface for real AI-powered diabetic retinopathy screening.

## Structure (To be scaffolded)
- **Upload Component**: Allows clinical users to upload retinal fundus images (.png, .jpg, .jpeg).
- **Result Dashboard**: Displays genuine model prediction (Class 0-4), referable status, and Grad-CAM visual explainability heatmap overlay.
- **API Client**: Communicates directly with the FastAPI backend.
